# NYTimes Audio Playlist extension

## Install in Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode** in the upper-right corner.
3. Click **Load unpacked**.
4. Choose this `extension` folder.
5. Pin **NYTimes Audio Playlist** from Chrome's Extensions menu.

Click the extension icon to open the playlist. Press the refresh icon at the top to scan the current NYTimes homepage and its linked articles using your existing browser session. The extension uses an existing NYTimes tab or opens one in the background, so sign in to NYTimes in Chrome first if your access requires it.

Playlists are saved by date in Chrome's local extension storage. Refreshing merges new discoveries into the current day and does not remove earlier dates.

The extension only requests access to NYTimes domains and local extension storage. It does not send your cookies or playlist to another server.
